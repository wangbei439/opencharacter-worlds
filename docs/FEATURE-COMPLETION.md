# 本轮补齐：物品、多角色、兼容

这轮完成的是此前约定的三个优先方向的可用实现，不等于复制整个酒馆，也不代表原规范所有发布验收已完成。

## 物品

- 所有者、持有人、物理位置分开。旧存档中 location 指向人物时兼容推导持有人。
- 赠送转移所有权和持有人；寄存只转移持有人；归还交回所有者；放下保留所有权；拾取不允许拿走别人的已归属物品。
- 持有人移动时，携带物品位置随之更新。寄存后不能远程使用或送走该物品。
- 支持按钮操作和少量明确的中文寄存/归还句式。含糊赠送不会自动改成另一个寄存动作。
- 事件、事实、历史回退和存档共同保留这些字段。未加入偷窃、放弃所有权、容器嵌套或复杂借用权限。

## 多角色

- 最多 12 名来自本地角色库的成员，各自读取自己的定义与世界书。
- 可指定当前发言者、排序、暂停发言和移出成员。人物世界记录与历史不因移出群聊而删除。
- 可手动触发 1–3 轮回复，选择按序或每轮随机，每人每轮一次，可停止。轮流回复不自动执行玩家输入中的事务，赠礼等需指定角色单独进行。
- 消息保存发言人；重生成使用原发言人，续写使用上一回复的发言人。其他角色历史发言带姓名标记。
- 完整存档包含成员原始卡和媒体，重导时重映射发言人、所有者和持有人。
- 不含自动自然发言调度、无限自动对话、私聊分频道或单卡自动拆分 NPC；世界中的在场约束仍生效。

## 兼容与编辑

- PNG / JSON V2、V3 与 CharX 继续交给 Character Foundry 解析，原始文件不变。CharX 媒体仍限于当前提取支持的图像类型，不承诺所有打包媒体行为完整还原。
- 世界书支持基本字段、大小写、完整词、四种附加条件、定义前后插入、扫描深度、预算、最多四轮递归及递归排除标记。
- 正则仅接受有长度/结构限制的子集，不支持分组、反向引用和复杂重复。不能执行的规则在上下文检查中说明原因，不悄悄套用近似结果。
- 脚本、Regex 文本替换、其他插件扩展不会执行；支持 char、user、group、description、personality、scenario、mesExamples 基础宏，其他宏原文保留。导入时提示这些兼容边界。
- 概率、持续/冷却、自动化、向量触发及深度注入等高级条目不执行。完整 SillyTavern 行为兼容尚未实现。

## 验证与后续

本地构建、46 项单元/运行时测试，以及多角色寄存、基础产品、创作室、真实 PNG 的受控浏览器流程通过；多角色寄存截图和结果位于 evidence/product/group-custody*。未使用用户 API 发起新调用。

真实模型下的新寄存/群聊行为、长篇大世界百轮一致性、实体 Android 和公开 URL 全流程仍需验收。原始规范列出的完整视觉动画与更细的帮助体验也不能因此宣布全部完成。


## 对话写作设置（2026-09-11）

- 每段故事可保存补充写作指令、场景覆盖和作者备注；不会修改原始角色卡或直接提交世界事实。
- 作者备注可放在系统提示或历史消息中。频率按当前历史中的用户消息数计算，0 为关闭；深度为备注后保留的消息数。重生成沿用该历史计数。Claude 原生接口会合并系统消息，不能保持历史插入位置。
- 最多 30 条常用回复，点击只填入输入框，用户确认发送后才请求模型。
- 基础宏不区分大小写、仅替换一次，不执行脚本或递归展开；未知宏保留。
- 最多 50 个本地写作预设，支持独立 ocw-writing JSON 导入导出。它不是 SillyTavern 完整预设格式，不含 API 配置或密钥。
- 写作设置随故事存档及分支保存；全局预设库需单独导出。新故事不自动继承其他故事的设置。
- 仍未实现完整提示词管理器、脚本/插件系统、复杂宏、向量检索、基于语义的自然发言调度等酒馆高级功能。

本轮新增 3 项单元测试，合计 49 项通过；写作设置浏览器流程见 evidence/product/writing.json。本轮没有新增依赖，许可证台账与边界见 DEPENDENCY-POLICY.md。


## 有限轮群聊调度（2026-09-11）

- 群聊设置中选择 1–3 轮及按序/随机顺序，点击「开始群聊」后执行；最多 12 人 × 3 轮，界面显示本次最大回复数。
- 每轮每名在场、未暂停的成员最多回复一次；随机模式尽量避免轮次交界处同一个角色连说两次。所有回复读取先前已保存的历史。
- 停止按钮中断当前请求，不再安排下一名角色；接口错误停止整段调度，不自动重试。刷新不恢复未完成调度。
- 轮数和顺序随故事、分支、完整存档保留，旧存档默认按序一轮。不会新增虚假的玩家消息，也不自动提交群聊中的世界事务。
- 这是用户触发的有限轮自动接话，不是语义驱动的自然发言选择、后台常驻自动对话或插件兼容。

51 项单元/运行时测试通过。多角色浏览器测试新增两轮四条回复、手动停止后无下一请求、503 错误停止及调度设置存档恢复；使用模拟接口，未调用用户真实 API。未新增或升级第三方依赖，449 项许可证台账检查通过。


## 写作指令独立开关（2026-09-11）

补充写作要求、场景覆盖、作者备注现可分别启用/暂停，暂停保留文字与频率设置。停用场景覆盖时恢复角色卡场景，包括常用回复中的 scenario 宏。开关随预设和故事存档保存；旧数据缺少开关时默认启用。上下文检查继续显示实际使用的段落，不包含停用文字。这仍不是可任意拖排全部系统提示的完整提示词管理器。

52 项单元/运行时测试及写作浏览器测试通过，验证实际请求排除停用内容、刷新保留开关及文字、旧预设默认兼容。没有新增依赖或真实 API 调用。

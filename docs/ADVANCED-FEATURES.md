# 高级扩展、宏和向量检索 V1

入口：输入框上方「对话写作设置」→「高级扩展与检索」。所有更改需点击保存。这是独立实现的 OpenCharacter 接口，不是 SillyTavern 插件或完整宏语言的兼容层。

## 提示词插件

支持安装、检查代码及许可证、启用/暂停、导出和卸载。最多 8 个，按安装列表顺序运行。每次模型生成前触发一次，返回文本添加到上下文中的「插件补充提示词」。重生成、续写和群聊各角色的生成也会触发。插件无法提交世界事务或改写原始卡。

文件示例见 `examples/quiet-narration.ocw-plugin.json`。这是本项目原创示例，附 MIT 许可证；未使用第三方实现。导入后手动启用并保存即可试用。

单个插件文件最多 256 KiB；包含多个插件的写作预设最多 4 MiB。

JSON 字段：

| 字段 | 内容 |
| --- | --- |
| format / version | `ocw-plugin` / `1` |
| id / name | 唯一的小写字母数字连字符 ID / 显示名 |
| license / source / licenseText | 声明 SPDX 许可证、来源和完整许可通知 |
| code | 异步 JavaScript 函数体，最多 24,000 字符 |
| enabled | 默认 false；安装和导入始终重置为 false |

函数仅收到 `input.character`、`input.user`、`input.message`；最后一项是当前触发输入，最多 8,000 字符。返回字符串最多 4,000 字符。插件输出是附加指令，用户启用前应检查代码及预期效果；许可证字段校验并不证明来源授权有效。当前只接收 MIT、Apache-2.0、BSD-2-Clause、BSD-3-Clause、ISC、0BSD 声明。

插件在无同源权限的 iframe 内创建独立 Worker。CSP 禁止网络及外部脚本，插件没有宿主 DOM、API 密钥或数据库引用。Worker 约 1.2 秒后被终止，宿主另设 1.5 秒超时；停止生成也会拆除沙箱。插件出错时跳过并提示，后续生成继续。没有插件依赖安装、远程下载、任意界面挂载或世界写入权限；不承诺任意恶意代码的资源消耗隔离或完整浏览器安全审计。

插件随故事和预设保存；从文件导入后全部暂停，需重新启用。插件不建立自己的持久状态。要更新同一 ID 的插件，先卸载旧版再导入新版。

## 高级宏

默认关闭。启用后对用于上下文的模板及常用回复进行有界解释，再做已有的基础宏替换。变量在每个模板开始时从初始变量复制，模板结束后丢弃；不会把反复构建上下文当成真实事件累计计数。

```text
{{setvar::tone::quiet}}
{{setvar::count::1}}
{{#if::tone::quiet}}
请保持克制的叙述。
{{#repeat::3}}
第 {{index}} 项，计数 {{getvar::count}}
{{addvar::count::2}}
{{/repeat}}
{{else}}
请使用活泼语气。
{{/if}}
```

- `setvar::name::value` 写入本次模板变量，`getvar::name` 读取，`addvar::name::number` 做数值相加。
- `#if::name::value` 比较字符串是否相等；只写 `#if::name` 判断非空。`else` 可省略。
- `#repeat::N` 重复 0–20 次；块内 `index` 从 1 开始，嵌套结束恢复外层索引。
- 上限：8 层嵌套、2,000 步、输入/输出各 65,536 字符。超限或语法错误会阻止本次生成并提示；不调用脚本执行器。
- 未识别的宏保留原文。变量值不会再次被当作高级宏程序执行。基础 char/user 等宏仍按原有单次替换规则处理。
- 当前没有全局永久变量、任意表达式、日期工具、随机函数或 SillyTavern 完整语法兼容。界面初始变量命名为 var1、var2 等，自定义名字可在模板用 setvar 声明或在预设 variables 对象中设置。

## 向量检索

这是实际调用嵌入模型并按余弦相似度排序的检索，不是把关键词评分改名。默认关闭，导入文件也重置为关闭。使用当前聊天提供商的地址及凭据，对 `/embeddings` 发送 `model`、`input`、`encoding_format: float`；必须填写该提供商实际支持的嵌入模型。当前仅支持这种兼容接口，原生 Claude 接口不支持，也不自动购买或下载模型。

启用后，当前角色参与的最近 100 条已提交事件摘要及当前输入会发送给接口，各截取最多 2,000 字符。已回退事件和其他角色私有事件在发送前排除。每批最多 16 条，结果验证索引、维度和有限数值；相似度不低于 0.25 的前 4 条可进入上下文。仍受上下文预算限制，可能被裁掉；上下文检查中的 vectorMemory 段显示最终保留内容及分数。

索引只在本页面内存中缓存，键包含接口地址、模型及精确摘要；缓存超过 500 条后清除。可手动清除，刷新后重建。角色权限、事件回退及删除每次重新过滤，不从缓存枚举旧事件。接口失败时提示并保留既有关键词/重要事件召回；停止操作会中断请求。

当前不索引完整聊天、世界书或外部文档，不支持独立嵌入提供商配置、磁盘向量库或本地嵌入模型。因此不能据此宣称完整酒馆检索生态已实现。

## 验证及参考

`npm run test:advanced` 是隔离浏览器流程，包含宏实际进入请求、插件安装默认关闭、网络/存储访问阻止、死循环超时、嵌入请求、向量缓存、私有事件过滤及导入重置。它使用模拟接口，不验证用户真实嵌入模型质量。单元测试还检查宏边界、向量畸形响应与许可清单校验。

行为和平台格式参考，仅阅读文档，未复制第三方源码：

- [MDN iframe sandbox](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe)
